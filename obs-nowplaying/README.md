# OBS Now Playing 表示システム

OBS Studioで再生している楽曲を検知して、視聴者向けWebページに「🎵 現在の曲」をリアルタイム表示するシステムです。
サンサンサンデーのようなXスペース配信で、リスナー用に別ウィンドウ（またはブラウザソースとしてOBS内）に流すことを想定しています。

## 仕組み

1. OBS Studio が持つ **obs-websocket (v5)** に、このNode.jsサーバーが接続する
2. OBS内の「メディアソース」で新しい曲が再生開始されると `MediaInputPlaybackStarted` イベントが飛ぶ
3. サーバーがそのメディアの再生中ファイルパスを取得し、ID3タグ（曲名・アーティスト）を読み取る
4. Socket.IOで全視聴者ページへ即時ブロードキャスト → ページが自動更新される

X スペース自体からは「今何の曲が流れているか」を取得するAPIは存在しないため、
**OBS側で曲を切り替えるタイミング＝配信で流れるタイミング**として検知する方式です。
（OBSの音声をそのままXスペースにルーティングして配信している構成を想定）

## 事前準備

### 1. OBS Studio 側の設定

1. OBS Studio 28以降を使用（obs-websocket v5が標準搭載）
2. メニューの `ツール > WebSocketサーバー設定` を開く
3. 「WebSocketサーバーを有効にする」にチェック
4. 「サーバーポート」（デフォルト 4455）と「サーバーパスワード」を確認・コピー
   - パスワードは `.env` に設定するのでこの画面を開いたままメモしておく
5. 曲を再生するメディアソースの名前を確認する（例: `BGM`）
   - **重要**: 曲を切り替える際は、同じメディアソースのファイルを差し替える（またはプレイリスト機能で自動送り）運用にしてください。
   - ファイル名は `アーティスト名 - 曲名.mp3` の形式、またはID3タグに曲名・アーティストが入っているとより綺麗に表示されます。

### 2. VS Code でこのプロジェクトを開く

1. このフォルダ（`obs-nowplaying`）を VS Code で開く（`File > Open Folder...`）
2. ターミナルを開く（`Ctrl + @` または `表示 > ターミナル`）
3. 以下を実行して依存パッケージをインストール:
   ```bash
   npm install
   ```
4. `.env.example` をコピーして `.env` を作成し、中身をOBSの設定値に合わせて書き換える:
   ```bash
   cp .env.example .env
   ```
   ```
   OBS_WS_URL=ws://127.0.0.1:4455
   OBS_WS_PASSWORD=（OBSでコピーしたパスワード）
   PORT=3000
   OBS_MEDIA_SOURCE_NAMES=BGM
   ```

### 3. 起動

```bash
npm start
```

- ターミナルに `視聴者ページ: http://localhost:3000` と表示されれば起動成功
- ブラウザで `http://localhost:3000` を開くと視聴者ページが見える
- OBSで曲（メディアソース）を再生すると、数秒以内にページの「NOW PLAYING」が切り替わる

開発中に自動リロードしたい場合は `npm run dev` を使ってください（ファイル保存で自動再起動します）。

## 視聴者への公開方法

- 社内/自分用: `http://localhost:3000` をそのままOBSの「ブラウザソース」として画面に重ねて配信画面に表示
- リスナーにも見せたい場合: このNode.jsサーバーを常時起動できるPC/VPS上で動かし、ポート開放や
  Cloudflare Tunnel / ngrok などで外部公開すればスマホからも閲覧できます

## カスタマイズポイント

| やりたいこと | 変更箇所 |
|---|---|
| 見た目を変えたい | `public/index.html` の `<style>` |
| 曲名の抽出ルールを変えたい | `server.js` の `extractTrackInfo()` |
| 複数の配信ソース(BGM/効果音等)を分けて表示したい | `OBS_MEDIA_SOURCE_NAMES` を編集し、`state` を配列化して拡張 |
| 過去の再生履歴をもっと見せたい | `public/index.html` の `historyList` 部分・`state.history` の件数上限 |
| Xスペースの返信欄にも自動投稿したい | サーバー側で `state.nowPlaying` 更新時にX API (v2 Post Tweet) を呼ぶ処理を追加 |

## トラブルシューティング

- **「OBSに未接続」のまま変わらない**
  → OBSのWebSocketサーバーが有効か、ポート/パスワードが `.env` と一致しているか確認
- **曲名が変わらない**
  → OBS側で同じメディアソースにファイルを差し替えているか（新規ソース追加ではなく既存ソースの中身を切り替える運用か）確認。
    別々のソース名を切り替える運用にしている場合は `OBS_MEDIA_SOURCE_NAMES` に対象ソース名をすべてカンマ区切りで指定してください。
- **曲名が変な文字化けになる**
  → ID3タグの文字コードが原因のことが多いです。ファイル名ベースの表示にフォールバックさせるか、
    事前にタグを整形しておくと安定します。
